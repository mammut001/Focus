# Privacy Policy for FocusFlow

Last Updated: February 11, 2026

FocusFlow does not collect, store, or transmit any personal data to external servers. 
All data is stored locally on your device using on-device storage (UserDefaults). 
Focus session data syncs only between your personal Apple Watch and iPhone via Apple's WatchConnectivity framework.

We do not use any third-party analytics, advertising, or tracking services.
